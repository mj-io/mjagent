iframe 嵌入测试（宿主页）

本页扮演 CRM：用 iframe 嵌入第三方客户应用 {{ app_origin }}。iframe 内点击「登录」后， 登录在顶层弹窗中完成（PingOne 登录页拒绝被嵌入，且 iframe 内 IdP / 应用 cookie 属第三方）， 弹窗通过 postMessage 把一次性 code 交回 iframe，iframe 再建立自己的（分区）会话。

iframe 属性：sandbox="allow-scripts allow-same-origin allow-forms allow-popups allow-popups-to-escape-sandbox allow-top-navigation-by-user-activation" （最后一项供弹窗不可用时兜底：如 iOS 企业微信 WKWebView 不支持 window.open，改为点击时顶层跳转登录、完成后跳回本页）； 本页 CSP frame-src {{ app_origin }}。对照：在顶层直接打开嵌入页。
